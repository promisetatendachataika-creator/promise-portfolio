Connect to GitHub

Changes are saved straight to your promise-portfolio repository, and the site updates from there. Your key is kept only in this browser.

How do I get an access key?
  1. On GitHub, open Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Click Generate new token. Give it a name like “Portfolio admin” and an expiry date.
  3. Under Repository access, choose Only select repositories and pick promise-portfolio.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Click Generate token, copy it, and paste it above. Don’t share it with anyone.
