# promise-portfolio

My personal site: the projects I've built, what I work with, and how to reach me.

I'm a Computer Science student at the University of Zimbabwe, looking for a 12-month industrial attachment.

## Running it locally

```bash
npm install
npm run dev
```

`npm run build` type-checks the code and writes the production site to `dist/`.

## Editing the content

All the text on the site (projects, skills, education, contact details) is in `src/content.ts`.
Change it there and the page updates; the layout code doesn't need to be touched.
